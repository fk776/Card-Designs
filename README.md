# Card Designs

A curated collection of web-based card templates and generators designed for personal events, celebrations, and traditional announcements. Each project is self-contained within its own directory for easy customization, styling, and deployment[cite: 1].

---

## 📂 Included Projects

* **Birthday Card Maker (`birthday-card-maker/`)**: An interactive template designed to create customizable birthday greetings and celebration cards[cite: 1].
* **Shok Sandesh Card (`shok-sandesh-card/`)**: A thoughtful, formal format tailored for traditional Indian condolence and memorial announcements[cite: 1].
* **Wedding Invite (`wedding-invite/`)**: An invitation card layout built for digital wedding invitations, RSVP displays, and event schedules[cite: 1].
